## 作品更新

作品在 Notion「橙子星球 → 小岛声场｜音乐库」中维护。只有勾选「发布」的歌曲会同步到这里。

本仓库每小时第 27 分钟尝试同步，也支持手动触发。网站独立在每小时第 17 分钟尝试更新，因此两个入口的更新时间可能略有不同；GitHub 排队和网站构建也可能延迟。Notion 附件会复制为仓库文件，不依赖会失效的临时下载地址。
